Introduction of Machine Learning




MACHINE
LEARNING

Machine Learning (ML) is a branch of Artificial Intelligence that enables computers to learn from data and improve their performance without relying on explicit programming instrcutions for every task.


How does work?


Machine Learning defines the pattern in training data to discover patterns and relationship between different pieces of instruction.

After learning those patterns, machine learning models can make prediction or decision when it is encountered with new information. Unlike traditional programming,its improves its accurancy through experience and continuous learning.

Supervised Learning


Learn More
  • model learn from labeled data, where target output is known.
  • Application:
  • risk assessment, image recognition, predictive analytics and fraud detection, comprises several types of algorithms.
  • ML project : hourse price prediction, medical insurance cost prediction, spam email detection.

Unsupervised Learning


Learn More
  • learn patterns from unlabelled data without knowing the correct answer/output.
  • Application: clustering , pattern recognition and recommendation system, anomally detection
  • example: customer segmentation, movie recommendation, product recommendation.

Reinforcement Learning


Learn More
  • learning from human feedback (RLHF), type of dynamic programming that trains algorithms using a system of reward and penalties by interacting with an environment.
    Rewards will encourage agent to maintain the good practice and throw the bad ones.
  • The agent repeats the action and gradually to learn best strategy.
  • Application: video game development, robot control, self driving car.
